# 청정해 인트라넷 연동 키트

청정해 인트라넷에 시스템 관리자만 보는 "로또 최적화" 메뉴를 붙이는 코드입니다. 계산은 이 저장소의 lotto-opt 엔진이 합니다.

| 파일 | 하는 일 |
|---|---|
| `server/lottoRouter.js` | 엔진을 실행하고 결과를 인트라넷 DB(`lotto_runs` 테이블)에 남기는 API, 저장된 결과의 당첨 확인 (`/api/lotto`, 시스템 관리자 전용) |
| `client/LottoOptimizer.jsx` | 화면: 방식(개선안·원안·분산 우선)·세트 수·시드 고르기, 결과 표, 그룹 번호, 검증 요약, 지난 결과, 번호 복사, CSV 저장, 당첨 확인(최신 회차·회차 지정·번호 직접 입력) |
| `test/` | 자동 시험 20개 (가짜 엔진 18개, 진짜 엔진 2개) |
| `APPLY.md` | 사무실 PC의 Claude Code가 따라 하는 적용 순서 |

## 적용 방법
사무실 PC에서 인트라넷 폴더를 연 Claude Code에 이 한 줄을 붙여 넣으세요.

> https://github.com/yangseokjin/lotto-opt 의 integrations/intranet/APPLY.md 대로 인트라넷에 로또 최적화 페이지를 붙여 줘. 재시작 전에는 꼭 물어봐.

인트라넷 재시작은 마지막에 한 번만 하고, 그 전에 꼭 물어보게 되어 있습니다.

## 알아 둘 점
- 실행 한 번에 보통 20~60초 걸리고, 한 번에 하나씩만 계산합니다.
- 시드를 비우면 매번 새 조합, 같은 시드를 넣으면 같은 결과가 나옵니다.
- 당첨 확인은 엔진의 `check` 명령을 씁니다. 엔진이 그 명령이 없는 버전이면 화면에 업데이트 안내가 나옵니다 (APPLY.md 맨 아래).
- 모든 조합의 1등 확률은 1/8,145,060으로 같습니다. 이 페이지는 여러 세트에 번호를 고르게 나눠 담을 뿐, 당첨 확률을 높이지 않습니다.
